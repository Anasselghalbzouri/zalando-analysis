# User stories — Phase 04

Personas are defined in [PRD.md](PRD.md) §3. Only the **member** was observed. Stories for the merchandiser are based on a HYPOTHESIS persona and need PO validation. No guest stories are written: the guest role is UNKNOWN (Q-03).

Each story lists the requirements it covers; its acceptance criteria are those of the linked requirements ([acceptance-criteria.md](acceptance-criteria.md)).
