# M06 — Product listing, filtering & sorting

**Status:** Analysed in Phase 02. Filter dialogs were opened and closed by reloading; **nothing was applied**. Labels and paths as in [M03](M03.md).

## 1. Module purpose
- **CONFIRMED:** One listing component renders a product grid with filters and sort for four contexts:
  - campaign `/campaigns/{id}`
  - category `/articles/categories/{id}`
  - brand `/brands/{code}`
  - search `/search-catalog?query=`

## 5. User interactions
- **CONFIRMED:** open and close a filter dialog. Choose one sort radio (single choice). Tick size checkboxes (multi-select control). Set a price range via inputs or sliders.
- **Not exercised:** applying any filter or sort. It's read-only, but it wasn't needed for UI discovery, so the result behaviour is UNKNOWN.
- **UNKNOWN:** how users reach products beyond the first 60 of 1 726 (see §12).

## 6. Inputs and outputs
- **Inputs:** sort key (5 enum values), size set, price min/max in whole euros (as displayed), brand, colour, composition, category, length.
- **Outputs:** product tiles and a live result count on the dialog's confirm button ("Afficher N résultats").
- **CONFIRMED:** the price bounds default to the context's min/max (8–299 € on `ZZO4RN5`). HYPOTHESIS: they're computed from the current result set.

## 7. Business rules
| ID | Rule | Class |
|---|---|---|
| BR-06-01 | Default sort is "Préférés" | CONFIRMED |
| BR-06-02 | Sort options: newest, preferred, price ascending, price descending, discount % | CONFIRMED |
| BR-06-03 | Filters are confirmed explicitly with a button that shows the result count ("Afficher 1 726 résultats"), not applied instantly | CONFIRMED (UI) / HYPOTHESIS (the count updates live as options change) |
| BR-06-04 | Size values are grouped by size system in tabs (e.g. "Chaussures") | CONFIRMED (one tab seen) / HYPOTHESIS (clothing contexts show more tabs) |
| BR-06-05 | The price filter range is bounded by the min/max price in the context | HYPOTHESIS (8/299 observed) |
| BR-06-06 | "Retirer" (clear this filter) is disabled when nothing is selected | CONFIRMED |
| BR-06-07 | A listing shows 60 products initially | CONFIRMED |
| BR-06-08 | Category listings add a "Longueur" (length) filter, so filters depend on context | CONFIRMED |
