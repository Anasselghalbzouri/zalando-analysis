# M05 — Event landings (verticals)

**Status:** Analysed in Phase 02 (2026-11-04). **Scope:** read-only navigation of the main-nav routes. Labels and paths as in [M03](M03.md).

## 1. Module purpose
- **CONFIRMED:** An *event* is a landing page at `/event/{id}` that groups live campaigns (M03) for one audience or theme: all sales, Femme, Homme, Enfant, Habitat, Sports, Premium. Each one is a curated campaign grid, not a product listing.

## 2. User roles and actors
- **Member:** CONFIRMED, as the session used.
- **Guest:** UNKNOWN.
- **Merchandiser:** HYPOTHESIS (hero choice, grid order and the "Premium : Édition Hiver" seasonal label imply curation).

## 4. Pages and UI components
Common template (CONFIRMED on all 8 routes):
1. USP bar, header and main nav (M01, M02)
2. H1 "ZALANDO PRIVÉ" (the same on every event)
3. **Hero banner**: image + caption + "Découvrir" button (verticals only)
4. H2 = event title ("Femme", "Premium : Édition Hiver"…)
5. Campaign grid (M03 tiles)
6. "Populaire dans votre région" product carousel
7. "Prochainement" upcoming list (M04)
8. Footer (M18)

## 5. User interactions
- **CONFIRMED:** click a campaign tile, click a carousel product, scroll. Scrolling lazily loads "Prochainement" and the footer: they were missing from unscrolled captures of `/event`, `/2`, `/3`, `/4` and present after End×2.
- **UNKNOWN:** where the hero "Découvrir" goes. It is a `button`, not a link. It wasn't clicked; the caption matches a campaign name on Femme ("Vans") and Premium ("BOSS – Homme"), so HYPOTHESIS: it opens that campaign.
- **UNKNOWN:** whether the "Populaire dans votre région" carousel scrolls or pages.

## 6. Inputs and outputs
- **Input:** the event ID in the path. No filters, sort or search on the event page (CONFIRMED: no filter group in any event tree).
- **Output:** an ordered list of campaign tiles, plus a hero, carousel and upcoming list.

## 8. State transitions
- **CONFIRMED:** event contents change over time. Femme had 79 tiles in Phase 01 (unscrolled) and 82 scrolled in Phase 02, and Phase 01 upcoming sales appear in Phase 02 grids (M03 BR-03-09). Part of the 79→82 change is from scrolling, so the time-based part is uncertain.
- **UNKNOWN:** whether an event itself has a lifecycle. HYPOTHESIS for "Premium : Édition Hiver" (seasonal label).
