# M07 — Product detail page (PDP)

**Status:** Analysed. Add-to-cart was exercised once with user authorization, then removed.
**Labels:** CONFIRMED / HYPOTHESIS / UNKNOWN / OUT OF SCOPE.
**Paths:** `a11y/…` = `evidence/a11y/…`. Evidence IDs are in [`evidence/INDEX.md`](../../evidence/INDEX.md). BR-IDs are in [business-rules.md](../requirements/business-rules.md).

## 1. Module purpose
CONFIRMED: Shows one campaign-scoped SKU with media, price, sizes, details, delivery and returns, and the purchase entry point.

## 2. User roles and actors
- **Member (logged-in shopper):** CONFIRMED, as the session used.
- **Guest:** UNKNOWN (not observed).

## 3. Entry points and navigation
CONFIRMED:
- URL `/campaigns/{cid}/articles/{sku}`, reached from listings, rails and search.
- Breadcrumb: Accueil › <campaign> (→ `/campaigns/{cid}`) › product.

Evidence: `a11y/product_desktop.yaml`, `a11y/pdp_add_no_size.yaml`, `a11y/pdp_added.yaml`.

## 4. Pages and UI components
CONFIRMED:
- **Media:** a tablist of 6 image tabs.
- **Product:** brand H1 link → `/brands/{code}`, then an H2 with type and colour.
- **Price:** sale price with the RRP struck through.
- **Countdown:** the campaign countdown.
- **Sizes:** region "Tailles" with radios in French third sizes (38, 38 2/3, 39 1/3 … 44 2/3). Low-stock text sits in the radio label, e.g. "43 1/3 Plus que 1 disponibles". A "Plus de tailles" checkbox.
- **Purchase:** button "Ajouter au panier".
- **Accordions:** Détails (attributes + "Référence" + model reference), Taille & Coupe, Composition, "Voir les informations sur la fabrication".
- **Loyalty:** a Plus block.
- **Delivery:** "Délai De Livraison" date window.
- **Returns:** "Retour gratuit durant 31 jours…".
- **Related:** "Voir plus" checkboxes.
- **Toast region:** a `list` above `main` holding `alert` messages.

## 5. User interactions
CONFIRMED:
- **Without a size:** click "Ajouter au panier" → alert **"Choisissez une taille"**. Nothing is added.
- **With a size:** select 39 1/3 → click "Ajouter au panier". Then:
  - alert **"Le produit a été mis à jour avec succès."**
  - the selected radio shows `[checked]`
  - **the "Ajouter au panier" button is no longer in the tree**
  - the header cart button becomes **"Votre panier - 1 Article - 20 minutes et 0 secondes restantes"**
- **OUT OF SCOPE:** "Activez Plus".

## 6. Inputs and outputs
- **Inputs:** size (radio, required).
- **Outputs:** price, stock hint, delivery window, toast, cart badge and timer.
- **SKU format (CONFIRMED pattern):** 9 alphanumerics, a hyphen, then 3 alphanumerics.
  - Some SKUs start with the brand code (`H1X`, `PU1`, `VA2`).
  - Many start with `ZZO` across unrelated brands (`ZZO3X3108-Q00` JAKO, `ZZO3K9537-Q00` Vans, `ZZO2HSM16-Q00` BOSS, `ZZO467J0F-A00` Ellesse).

## 7. Business rules
- **BR-07-01 CONFIRMED:** the PDP repeats the campaign countdown (BR-03-02).
- **BR-07-02 CONFIRMED:** per-size low-stock label "Plus que N disponibles". N fell from 3 (Phase 01) to 1 (Phase 02) on the same size, so the value is live. The threshold is UNKNOWN. Grammar defect: "1 disponibles".
- **BR-07-03 CONFIRMED:** the PDP shows free returns within 31 days of delivery. This conflicts with the help page (30 days) and the CGV (14-day legal withdrawal); see BR-17-04.
- **BR-07-04 CONFIRMED:** a delivery date window is shown (4 days wide, starting 2 days after the visit).
- **BR-07-05 HYPOTHESIS:** the SKU prefix is the brand code for some articles, and `ZZO` is a platform number range.
- **BR-07-06 CONFIRMED:** size selection is required before adding to the cart (alert "Choisissez une taille").
- **BR-07-07 CONFIRMED:** adding to the cart starts a **20-minute reservation** (BR-14-02).
- **BR-07-08 CONFIRMED:** after adding, the PDP hides "Ajouter au panier". HYPOTHESIS: one unit per SKU per member, or the button is replaced while the reservation is active.

## 8. State transitions
CONFIRMED: `no size → [add] → error alert`; `size selected → [add] → success alert + reserved + add button hidden`.

## 9. Dependencies on other modules
M03 (campaign), M09 (brand), M12, M13, M14 (cart), M16, M17, M06 ("Voir plus").

## 10. Observable validation and error states
CONFIRMED:
- Error alert "Choisissez une taille".
- Success alert "Le produit a été mis à jour avec succès." The wording says "updated", not "added".

## 11. Responsive behaviour
UNKNOWN. Only a 1280×720 desktop viewport was rendered (see platform-overview §3).
