## 1. Module purpose
CONFIRMED: Previews scheduled campaigns (the M03 Scheduled state) and offers a per-sale opt-in, "Informez moi".

## 2. User roles and actors
- **Member (logged-in shopper):** CONFIRMED, as the session used.
- **Guest:** UNKNOWN (not observed).
- **Notification channel and recipient:** UNKNOWN.

## 3. Entry points and navigation
CONFIRMED:
- Section "Prochainement" (H2) near the bottom of `/event`, `/event/1`, `/2`, `/3`, `/4`, `/58` and `/3774`.
- It loads lazily, so it only appears after scrolling.
- Absent on `/3849` Premium.

Evidence: `a11y/home_scrolled.yaml`, `page_*_scrolled.yaml`, `page_habitat.yaml`.

## 4. Pages and UI components
CONFIRMED:
- **First item:** a newsletter promo link to `/myaccount/newsletter#panel=myaccount-newsletter-subscribe`.
- **Then N tiles** (33 at ~17:10 UTC), each with:
  - an H3 name (not a link)
  - an image
  - "Démarre dans <countdown>" or "Démarre le <jour date> <HH:MM>"
  - a button "Informez moi"

## 5. User interactions
OUT OF SCOPE: clicking "Informez moi" or the newsletter link. Both change account state and need explicit authorization (see open-questions Q-01).

## 6. Inputs and outputs
- **Output:** name, image, start time.
- **Input:** the button. Its target and payload are UNKNOWN.

## 7. Business rules
- **BR-04-01 CONFIRMED:** the upcoming list is identical across event landings, i.e. global (see BR-05-04).
- **BR-04-02 CONFIRMED:** tiles carry no campaign link or ID (BR-03-11).
- **BR-04-03 CONFIRMED:** start times use relative and absolute formats (BR-03-12).
- **BR-04-04 CONFIRMED:** all 33 next-day entries share one start time, "jeu. 5 novembre 06:00". The timezone is UNKNOWN (see M03 §12).
- **BR-04-05 CONFIRMED (help page):** about ten new sales go live every day, at 07:00 on weekdays and 08:00 at weekends.
- **BR-04-06 CONFIRMED:** the newsletter offers daily and/or weekly sales emails (M15). It's the documented way to stay informed of upcoming sales.

## 8. State transitions
- **CONFIRMED:** Upcoming → Live (BR-03-09).
- **UNKNOWN:** the button state after subscribing (a toggle? "Inscrit"?) and how to unsubscribe.
