# M08 — Search with brand suggestions

**Status:** Phase 01 captures.
**Labels:** CONFIRMED / HYPOTHESIS / UNKNOWN / OUT OF SCOPE.
**Paths:** `a11y/…` = `evidence/a11y/…`. Evidence IDs are in [`evidence/INDEX.md`](../../evidence/INDEX.md). BR-IDs are in [business-rules.md](../requirements/business-rules.md).

## 1. Module purpose
CONFIRMED: Header search that suggests brands and opens a search-results listing.

## 2. User roles and actors
- **Member (logged-in shopper):** CONFIRMED, as the session used.
- **Guest:** UNKNOWN (not observed).

## 3. Entry points and navigation
CONFIRMED:
- Combobox "Quelles sont les offres du jour ?" in the header on every page.
- A suggestion goes to `/search-catalog?query=<brand>&searchAnonId=<id>`.

## 4. Pages and UI components
CONFIRMED:
- A listbox of brand suggestions for "nike": Nike, Nike Sportswear, Nike Performance, Nike SB, Nike Golf.
- A close button and a clear button. Their 2 ARIA labels are in German.
- Results use the M06 listing.

Evidence: `a11y/search_suggest.yaml`, `a11y/search_results.yaml`.

## 5. User interactions
- **CONFIRMED:** type → suggestions → select.
- **UNKNOWN:** what pressing Enter on free text does.

## 6. Inputs and outputs
- **Inputs:** free text.
- **Outputs:** brand suggestions and a results grid.
- `searchAnonId` is redacted in the evidence.

## 7. Business rules
- **BR-08-01 CONFIRMED:** the suggestions observed were brands only.
- **BR-08-02 CONFIRMED:** results span campaigns (products from several campaign IDs).
- **BR-08-03 HYPOTHESIS:** `searchAnonId` is an anonymous search-session ID for analytics.

## 8. State transitions
CONFIRMED: typing → suggestions open → selected → results page.

## 9. Dependencies on other modules
M06, M03, M20.

## 10. Observable validation and error states
UNKNOWN: the no-results state and the minimum query length.

## 11. Responsive behaviour
UNKNOWN. Only a 1280×720 desktop viewport was rendered (see platform-overview §3).

## 12. Unknowns and assumptions
- **UNKNOWN:** free-text, category or campaign suggestions, and typo tolerance.
- **CONFIRMED defect:** mixed-language ARIA labels (German).
