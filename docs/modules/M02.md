# M02 — Main navigation & mega-menus

**Status:** Phase 01 captures, re-read in Phase 02.
**Labels:** CONFIRMED / HYPOTHESIS / UNKNOWN / OUT OF SCOPE.
**Paths:** `a11y/…` = `evidence/a11y/…`. Evidence IDs are in [`evidence/INDEX.md`](../../evidence/INDEX.md). BR-IDs are in [business-rules.md](../requirements/business-rules.md).

## 1. Module purpose
CONFIRMED: Top-level navigation into the event landings (M05) and, through mega-menus, into the category listings (M06).

## 2. User roles and actors
- **Member (logged-in shopper):** CONFIRMED, as the session used.
- **Guest:** UNKNOWN (not observed).

## 3. Entry points and navigation
CONFIRMED:
- `navigation "Main"` appears only on `/event*` pages.
- Text links route client-side to `/event/{1,2,3,4,58,3774,3849}`.
- Chevron buttons open the panels.

Evidence: `evidence/nav-routes.json`, `a11y/menu_*.yaml`.

## 4. Pages and UI components
CONFIRMED:
- **Items (7):** Toutes les ventes, Femme, Homme, Enfant, Habitat, Sports, Premium : Édition Hiver.
- **Mega-menu:** 4–5 columns (Vêtements, Chaussures, Accessoires, Équipement, Beauté/Soins). Habitat uses its own columns.
- **Enfant** has Garçon/Fille toggles.
- **Sports:** the panel is empty.
- **Premium** has no chevron.

Full tree: [sitemap §3](../discovery/sitemap.md).

## 5. User interactions
CONFIRMED: menus open on hover (mouse) or Enter (keyboard). Each menu entry goes to `/articles/categories/{id}`.

## 6. Inputs and outputs
- **Input:** hover or focus.
- **Output:** category links with numeric IDs.

## 7. Business rules
- **BR-02-01 CONFIRMED:** only event pages show the main nav. Campaign, PDP, brand and search pages don't.
- **BR-02-02 CONFIRMED:** Premium is a nav item without a mega-menu.
- **BR-02-03 HYPOTHESIS:** the Sports panel is empty because a curated event has no taxonomy.

## 8. State transitions
- **CONFIRMED:** panel closed → open (hover or Enter) → closed (mouse leaves).
- **UNKNOWN:** Escape-key handling.

## 9. Dependencies on other modules
M05 (targets), M06 (category listings), M01.

## 10. Observable validation and error states
None observed.

## 11. Responsive behaviour
UNKNOWN. Only a 1280×720 desktop viewport was rendered (see platform-overview §3).

## 12. Unknowns and assumptions
- **UNKNOWN:** whether menus are CMS-managed per season. The label "Édition Hiver" suggests seasonal content.
- **UNKNOWN:** touch behaviour.
